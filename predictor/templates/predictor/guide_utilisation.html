À quoi sert PredictNeed IA ?

PredictNeed IA est une plateforme qui aide une entreprise à comprendre ce que font les visiteurs sur son site web. Le but n'est pas seulement de compter les visites, mais de transformer le comportement en information commerciale : quelles pages ont été consultées, quelle intention semble apparaître, quel lead mérite une relance, quelles campagnes amènent les meilleurs visiteurs.

Pour le dirigeant

Le dashboard donne une lecture simple de l'activité commerciale : visiteurs, leads, intentions fortes, sources de trafic et opportunités.

Pour l'équipe commerciale

Les leads sont priorisés avec un score, un profil probable, un message éventuel et le parcours consulté avant la prise de contact.

Pour le marketing

Les sources, UTM, campagnes et pixels permettent de mieux comprendre les canaux qui créent de l'intérêt et de préparer le retargeting.

Pour la conformité

Le consentement cookies, les textes à copier et les réglages de sécurité aident le client à utiliser la plateforme proprement.

Démarrage rapide

1

Créer le compte professionnel

Le client crée un compte avec son identifiant, son email professionnel, son entreprise, son secteur d'activité et son site web principal.

Après connexion, le lien Dashboard apparaît dans la navigation du site public pour revenir facilement à l'espace client.

2

Vérifier les paramètres

Dans Dashboard > Paramètres, le client vérifie son profil, son email, son nom d'entreprise, son secteur et ses paramètres de connexion.

Cette étape rend l'espace plus professionnel avant l'installation du script ou la présentation à une équipe.

3

Installer le script

Le script fourni dans le dashboard ou dans le module Connecteurs doit être placé sur le site client, idéalement avant la balise </body>.

Une fois installé, il affiche le widget visiteur, lit les événements autorisés et remonte les informations dans PredictNeed IA.

4

Lire les premiers signaux

Après les premières visites, le dashboard affiche les sessions, pages consultées, sources, messages visiteurs, leads, intentions et opportunités.

Si aucune donnée ne remonte, il faut vérifier la clé API, le domaine, le consentement cookies et l'emplacement du script.

Paramètres du compte, du profil et de connexion

Comme dans un espace client professionnel classique, PredictNeed IA possède une page Paramètres. Elle est accessible depuis le header du dashboard. Elle ne contient pas les réglages internes administrateur comme Stripe, les clés serveur ou Django Admin.

Paramètres de compte

Cette partie résume l'entreprise, le statut d'abonnement, les sites suivis et le rattachement des données au compte professionnel. Elle aide le client à comprendre quel espace il utilise.

Paramètres du profil

Le profil regroupe le prénom, le nom, l'identifiant, l'email professionnel, le nom de l'entreprise et le secteur d'activité. Ces informations peuvent être mises à jour par le client.

Paramètres de connexion

Cette zone permet de changer le mot de passe. L'utilisateur doit saisir son mot de passe actuel, choisir un nouveau mot de passe et le confirmer. La session reste ouverte après validation.

Ce que le client ne doit pas voir

Le client ne gère pas Stripe, les clés secrètes OAuth, les variables serveur, les webhooks ou l'administration Django. Ces éléments restent internes à PredictNeed IA.

Comprendre le dashboard

Le dashboard est la page centrale. Il sert à voir rapidement si le site attire des visiteurs utiles, quelles actions ils réalisent et quels contacts doivent être traités en priorité.

Vue d'ensemble

Elle résume les sites connectés, sessions visiteurs, intentions fortes et leads capturés. C'est la première lecture à faire chaque jour.

Modules actifs

Cette zone indique les modules disponibles pour le site : prédiction, segmentation, e-commerce, visualisations, historique, multi-canal, connecteurs, publicité et sécurité.

Analyse visiteurs

Elle affiche les appareils, le rebond, les pages vues, les clics, le temps moyen et les sources principales. Elle aide à détecter les comportements intéressants ou les points faibles.

Messages visiteurs

Les messages envoyés depuis le widget apparaissent avec le site, la date, le contact disponible, le score, l'intention et le parcours.

Opportunités

Une opportunité représente une piste commerciale à suivre. Elle peut être créée depuis un lead et avancée selon l'étape de vente.

Automatisations

Les automatisations email préparent des réponses ou relances selon les leads, le profil détecté, l'entreprise et le besoin probable.

Lire les visiteurs, pages regardées et messages

Une des valeurs importantes de PredictNeed IA est de montrer les pages que les visiteurs ont consultées. Cela aide à comprendre le besoin réel avant de contacter le prospect.

Session visiteur

Une session correspond à une visite. Elle peut contenir plusieurs pages vues, des clics, un temps passé, une source, un appareil et parfois un message ou un lead.

Pages regardées

Le parcours montre les dernières pages consultées. Par exemple : accueil, service, tarifs, contact. Ce chemin donne une indication sur l'étape mentale du visiteur.

Entreprise détectée

Lorsque des signaux le permettent, PredictNeed IA peut afficher une entreprise probable ou un signal associé au visiteur. Cette information doit être utilisée comme indice commercial, pas comme certitude absolue.

Message visiteur

Le widget permet au visiteur d'écrire un message. Ce message reste disponible dans le dashboard pour répondre vite, créer une opportunité ou lancer une relance.

Modules du dashboard

Prédiction avancée

Analyse les signaux de navigation pour estimer le besoin probable, le profil et l'intention du visiteur. Utile pour prioriser les leads.

Segmentation

Classe les visiteurs selon leur comportement : visiteurs chauds, curieux, hésitants, visiteurs prix, visiteurs récurrents ou segments issus de campagnes.

E-commerce

Met l'accent sur les signaux produits, les pages tarifaires, l'intention d'achat, les abandons potentiels et les parcours avant contact.

Visualisations

Présente les données sous forme de graphiques et listes lisibles pour suivre l'évolution des visites, leads, intentions et sources.

Historique

Conserve les événements importants d'une session afin de relire le chemin suivi par un visiteur ou de comparer les périodes.

Multi-canal

Compare les sources de trafic : Google, réseaux sociaux, e-mail, accès direct, référents et campagnes UTM.

Connecteurs

Centralise le script d'installation, les pixels de retargeting, les comptes externes disponibles et les mentions légales à copier.

Publicité

Analyse les sessions issues de campagnes publicitaires ou d'UTM afin de rapprocher trafic, intention et leads.

Sécurité

Récapitule les éléments de conformité, consentement, scripts actifs, accès et informations à transmettre au client.

Connecteurs et installation

Le module Connecteurs répond à une question simple : comment relier le site du client à PredictNeed IA et comment transmettre les bons événements aux outils marketing autorisés.

Script PredictNeed IA

C'est le script principal. Il collecte les événements autorisés, affiche le widget message, applique le consentement et transmet les signaux au dashboard.

Où installer le script ?

Le script doit être installé sur toutes les pages importantes du site, idéalement dans le thème global, le gestionnaire de balises ou avant </body>.

Comptes publicitaires OAuth

Google Ads, Meta Ads, LinkedIn Ads ou TikTok Ads peuvent apparaître seulement quand leurs clés développeur sont configurées côté serveur.

Pourquoi un bouton peut être absent ?

Si une plateforme OAuth n'est pas configurée par PredictNeed IA, elle n'est pas affichée au client. Cela évite de lui montrer des réglages qui ne fonctionnent pas encore.

Stripe et paiement

Stripe concerne l'abonnement à PredictNeed IA. Le client final ne doit pas configurer Stripe dans son dashboard. Cette partie reste interne.

Textes légaux à copier

Le module fournit des contenus pour la politique de confidentialité et la politique cookies du site client afin d'expliquer le suivi utilisé.

Pixels de retargeting

Le retargeting permet à une entreprise de recibler des visiteurs ayant déjà consulté une page ou montré une intention. PredictNeed IA peut déclencher les pixels configurés uniquement lorsque le consentement marketing le permet.

Principe

Un visiteur consulte une page produit ou tarif. Si le pixel publicitaire est configuré et si le visiteur accepte le marketing, un événement est envoyé à la plateforme publicitaire.

Meta Pixel ID

Identifiant fourni par Meta pour Facebook et Instagram. Il permet des événements comme PageView, ViewContent et Lead.

Google Ads ID

Identifiant de type AW-... utilisé pour envoyer des événements publicitaires à Google Ads.

Label conversion Google

Complément du Google Ads ID pour marquer une conversion précise, par exemple une demande de contact ou un formulaire envoyé.

TikTok, LinkedIn et Pinterest

Ces IDs servent à transmettre les visites et conversions aux plateformes concernées pour la mesure, les audiences et les campagnes.

À vérifier

Le pixel doit être correct, le script doit être installé, le site doit recevoir des visites et le consentement marketing doit être accepté.

Cookies, consentement et conformité

PredictNeed IA doit respecter le choix du visiteur. Le widget de message peut rester disponible comme outil de contact, mais les événements analytics et les pixels marketing dépendent du consentement configuré.

Tout accepter

Active les finalités autorisées, dont l'analytics et les pixels marketing si le visiteur accepte ces choix.

Tout refuser

Bloque les événements analytics et les pixels publicitaires. Le pop-up message peut rester accessible comme formulaire de contact.

Personnaliser

Permet de choisir séparément les finalités. Les pixels marketing ne doivent pas partir sans accord marketing.

Réduire le pop-up

Le visiteur peut fermer ou réduire le widget s'il ne souhaite plus le voir. Le choix cookies et le widget message sont deux comportements distincts.

Comment expliquer PredictNeed IA à un client

Phrase simple

PredictNeed IA montre ce que les visiteurs regardent sur votre site, détecte les signaux d'intérêt et vous aide à transformer ces visites en contacts commerciaux exploitables.

Exemple concret

Un visiteur regarde la page d'accueil, la page services, puis la page tarifs. PredictNeed IA peut afficher ce parcours, donner une intention probable et recommander une action commerciale.

Argument commercial

Beaucoup d'entreprises ont du trafic mais ne savent pas quoi en faire. PredictNeed IA donne une lecture plus claire : qui s'intéresse à quoi, quelles pages déclenchent l'intérêt et quels leads traiter en premier.

Limite à expliquer

Les scores et entreprises détectées sont des aides à la décision. Ils ne remplacent pas le jugement humain, la qualification commerciale ou la vérification directe avec le prospect.

Questions fréquentes

Où le client trouve-t-il les paramètres de compte ?

Dans le dashboard, un lien Paramètres donne accès au profil, à l'entreprise, à l'email et au changement de mot de passe.

Pourquoi je ne vois pas certains boutons Google Ads ou Meta Ads ?

Parce qu'ils apparaissent au client seulement quand la connexion OAuth est configurée côté PredictNeed IA.

Le client doit-il gérer Stripe ?

Non. Stripe sert à encaisser l'abonnement PredictNeed IA et reste une configuration interne administrateur.

Le pop-up message dépend-il des cookies publicitaires ?

Non. Il peut s'afficher comme outil de contact. Les pixels publicitaires restent bloqués sans consentement marketing.

Quand les réseaux sociaux peuvent-ils recibler un visiteur ?

Quand le client a renseigné ses IDs de pixels, installé le script mis à jour et obtenu le consentement marketing du visiteur.

Que faut-il vérifier avant de vendre la plateforme ?

Le domaine, les pages légales, le paiement, l'email SMTP, les scripts d'installation, les consentements, les paramètres client et les modules activés par site.
