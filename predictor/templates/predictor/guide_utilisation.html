Guide d'utilisation et glossaire PredictNeed IA

Une référence complète pour comprendre la plateforme, installer le script, lire le dashboard, configurer les connecteurs et expliquer les principaux mots utilisés dans PredictNeed IA.

Démarrage Dashboard Modules Connecteurs Retargeting Cookies Glossaire FAQ

Démarrage rapide

1

Créer le compte

Le client crée son compte professionnel, renseigne son entreprise, accepte les conditions et active son accès selon l'abonnement prévu.

2

Ajouter le site

Le site client est enregistré avec son nom, son domaine et les modules nécessaires. Chaque site reçoit une clé API unique.

3

Installer le script

Le script fourni dans le dashboard doit être placé sur le site client, idéalement avant la balise de fermeture </body>.

4

Vérifier les données

Après les premières visites, le dashboard affiche sessions, pages vues, sources, intentions, leads et opportunités.

Comprendre le dashboard

Vue d'ensemble

Elle résume l'activité : nombre de sessions, pages vues, clics, temps passé, leads capturés, intentions fortes et opportunités commerciales.

Sessions visiteurs

Une session correspond à une visite suivie sur le site. Elle regroupe les pages vues, la source, l'appareil, le navigateur et les événements.

Pages consultées

PredictNeed IA indique les pages visitées afin de comprendre le parcours avant une demande de contact ou une intention forte.

Leads et messages

Quand un visiteur écrit via le pop-up ou laisse ses coordonnées, le lead apparaît avec son message, son score et son statut de suivi.

Modules du dashboard

Prédiction avancée

Analyse les signaux de navigation pour estimer le besoin probable, le profil et l'intention du visiteur.

Segmentation

Classe les visiteurs selon leur comportement : chauds, curieux, hésitants, visiteurs prix ou visiteurs récurrents.

E-commerce

Met l'accent sur les signaux produits, pages tarifaires, intention d'achat et parcours avant contact.

Visualisations

Présente les données sous forme de graphiques et listes lisibles pour suivre l'évolution des visites et des leads.

Historique

Conserve les événements importants d'une session pour relire le chemin suivi par un visiteur.

Multi-canal

Compare les sources de trafic : Google, réseaux sociaux, e-mail, accès direct, référents et campagnes UTM.

Connecteurs

Centralise le script d'installation, les pixels de retargeting, les comptes externes reliés et les mentions légales à copier.

Publicité

Analyse les sessions issues de campagnes publicitaires ou d'UTM afin de rapprocher trafic, intention et leads.

Sécurité

Récapitule les éléments de conformité, consentement, scripts actifs et informations à transmettre au client.

Connecteurs et installation

Script PredictNeed IA

C'est le script principal. Il collecte les événements autorisés après consentement, affiche le pop-up message et transmet les signaux au dashboard.

Comptes publicitaires OAuth

Ces connexions permettent de relier des comptes Google Ads, Meta Ads, LinkedIn Ads ou TikTok Ads quand les clés développeur sont activées côté serveur.

Pourquoi un bouton peut être absent

Si une plateforme OAuth n'est pas encore configurée par PredictNeed IA, elle n'est pas affichée au client. L'administrateur peut voir l'état de configuration.

Stripe

Stripe concerne l'abonnement et le paiement de PredictNeed IA. Cette configuration est interne et ne doit pas être gérée par le client final.

Pixels de retargeting

Le retargeting permet de retrouver, sur une plateforme publicitaire, des visiteurs qui ont consulté une page ou envoyé un formulaire. PredictNeed IA peut déclencher les pixels configurés uniquement après consentement marketing.

Meta Pixel ID

Identifiant fourni par Meta pour Facebook et Instagram. Il permet les événements PageView, ViewContent et Lead.

Google Ads ID

Identifiant de type AW-... utilisé pour envoyer des événements publicitaires à Google Ads.

Label conversion Google

Complément du Google Ads ID pour marquer une conversion précise, par exemple une demande de contact.

TikTok Pixel ID

Identifiant TikTok qui permet de mesurer les visites, contenus consultés et formulaires envoyés.

LinkedIn Partner ID

Identifiant LinkedIn Insight Tag utilisé pour les audiences et la mesure sur LinkedIn.

Pinterest Tag ID

Identifiant Pinterest permettant de transmettre les visites et leads à Pinterest Ads.

Cookies, consentement et conformité

Accepter

Active les finalités autorisées, dont le tracking analytics et les pixels marketing si le visiteur accepte ces choix.

Refuser

Bloque les événements analytics et les pixels publicitaires. Le pop-up de message peut rester disponible comme formulaire de contact.

Personnaliser

Permet de choisir séparément les finalités. Les pixels marketing ne partent pas sans accord marketing.

Mentions à copier

Le module Connecteurs fournit des textes à ajouter dans la politique de confidentialité et la politique cookies du client.

Glossaire

Audience

Groupe de visiteurs utilisable pour une analyse ou une campagne publicitaire.

Campagne UTM

Paramètre ajouté à une URL pour identifier une campagne marketing.

Consentement marketing

Accord donné par le visiteur pour les contenus personnalisés et pixels publicitaires.

Conversion

Action importante : formulaire envoyé, contact demandé, inscription ou achat.

Événement

Action enregistrée : page vue, clic, temps passé, lead ou conversion.

Intention forte

Signal indiquant qu'un visiteur semble proche d'une action commerciale.

Lead

Personne ayant laissé un email, téléphone ou message de contact.

Pixel

Script publicitaire qui transmet un événement à une plateforme comme Meta ou Google.

Retargeting

Publicité adressée à des personnes ayant déjà visité une page ou montré un intérêt.

Score

Note qui aide à prioriser les visiteurs ou leads selon les signaux observés.

Session

Visite d'un utilisateur sur le site pendant une période donnée.

Source de visite

Origine du trafic : Google, social, email, accès direct ou référent.

Tracker

Script PredictNeed IA installé sur le site client pour remonter les signaux autorisés.

UTM source

Paramètre indiquant la source d'une campagne, par exemple google, facebook ou newsletter.

ViewContent

Événement publicitaire indiquant qu'une page ou un contenu important a été consulté.

Questions fréquentes

Pourquoi je ne vois pas certains boutons Google Ads ou Meta Ads ?

Parce qu'ils apparaissent au client seulement quand la connexion OAuth est configurée côté PredictNeed IA.

Le client doit-il gérer Stripe ?

Non. Stripe sert à encaisser l'abonnement PredictNeed IA et reste une configuration interne administrateur.

Le pop-up message dépend-il des cookies publicitaires ?

Non. Il peut s'afficher comme outil de contact. Les pixels publicitaires restent bloqués sans consentement marketing.

Quand les réseaux sociaux peuvent-ils recibler un visiteur ?

Quand le client a renseigné ses IDs de pixels, installé le script mis à jour et obtenu le consentement marketing du visiteur.

Que faut-il vérifier avant de vendre la plateforme ?

Le domaine, les pages légales, le paiement, l'email SMTP, les scripts d'installation, les consentements et les modules activés par site.
